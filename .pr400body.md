## What
The Claude Code Projects book launch page (`/blog/claude-code-projects-book-2026/`) currently renders a **"📚 My other books"** block that cross-promotes the *other* four books (Kubernetes, Red Hat OpenShift, Generative AI, Building & Scaling AI on Kubernetes). The request: show only **this book's** cover and **no cross-promotion of other books** on this page.

## How
A per-post frontmatter flag `noCrossPromo` (opt-in) that tells `src/pages/blog/[slug].astro` to skip the "My other books" block. Applied only to the Claude Code Projects post, so no other post is affected.

- `src/content.config.ts` — declare optional `noCrossPromo` (boolean, default false).
- `src/content/blog/claude-code-projects-book-2026.mdx` — `noCrossPromo: true`.
- `src/pages/blog/[slug].astro` — skip the "My other books" block when `noCrossPromo` is set (this book's own cover, CTA and description remain).

This also removes the other-books links from the generated HTML, which clears the link-checker's 4 cross-promo 404s that were failing the build (`Building & Scaling AI…`, `Kubernetes: Production…`, `Red Hat OpenShift…`, `Architecting Generative AI…`).

## Also included (unblocks the required Build check)
`src/content/blog/ai-tech-summit-skopje-2026-lab-from-demo-to-production.mdx` — `category: "MLOps"` → `"AI"`.
The site has a deliberate `mlops → ai` 301 (old category consolidated into `AI`). #396 introduced this post with the retired `MLOps` category, which regenerates `/blog/categories/mlops/` and collides with that redirect, failing the "Validate SEO fixes" step (a pre-existing bug on `main`). Changing the singular `category` to `AI` matches the redirect and its sibling Skopje posts; the `MLOps` tag is unchanged. This is a separate, clearly-scoped commit — revert just it if you'd prefer to handle the category differently.

## Why not a global change
Other posts legitimately use the "My other books" block, so this is opt-in per post.

## Verification
- No other post sets `noCrossPromo` (only the Claude Code Projects post), so no other page changes.
- This book's cover, CTA and description are untouched.
- The mlops category fix removes the category/redirect conflict; the `mlops → ai` redirect still resolves inbound links.
- `astro build` is heavy (6 GB) and OOMs on this M4 mini, so the change is validated in CI.
