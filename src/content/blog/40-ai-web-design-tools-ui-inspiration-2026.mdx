Most AI-generated websites look like they came from the same template: familiar gradients, predictable cards, interchangeable hero sections. The coding tool is not always the problem. Often the problem is **a weak design reference and an underspecified prompt**.

This is my curated list of **40 websites and tools** to help founders, freelancers, designers, and developers build more distinctive sites with AI. It covers complete prompts, design systems an agent can read, galleries worth studying, reusable UI components, motion effects, and the coding tools that tie everything together.

**If you open only one link, start with [Scrolltide](https://www.scrolltide.co/).** Then explore the category that matches your current bottleneck. This is a practical directory, not a claim that any one tool can replace user research, accessibility reviews, or engineering judgment.

## The fastest way to use this list

1. **Choose a direction.** Study two or three real designs for typography, spacing, hierarchy, and motion.
2. **Give your agent precise instructions.** Start with a complete prompt or a `DESIGN.md` file, then specify your content, audience, constraints, and tech stack.
3. **Use components deliberately.** Reuse accessible UI patterns instead of rebuilding buttons, forms, or navigation.
4. **Validate before shipping.** Check mobile breakpoints, keyboard navigation, contrast, loading performance, interactions, and the final diff.

### 2. [DESIGN.md](https://designmd.ai/)

Design systems expressed as Markdown that coding agents can read. Define colors, typography, spacing, components, and visual rules once, then use that guidance to keep generated pages consistent.

### 3. [Vibe Prompts](https://vibeprompts.dev/)

Ready-made prompts for dashboards, landing pages, and common interface directions. Useful when your first prompt needs more specificity than 'make it look modern'.

## Real-world design inspiration and UX patterns

### 4. [Minimal Gallery](https://minimal.gallery/)

A curated source of restrained, high-end web design references. Study its typography, whitespace, and content hierarchy before adding animation.

### 5. [Kage](https://kage.design/)

Real web-design inspiration paired with prompts you can use to turn a visual direction into an AI-assisted implementation.

### 6. [Refero Styles](https://styles.refero.design/)

A collection of 2,000+ AI-readable website style references, including typography, colors, spacing, components, and DESIGN.md files.

### 7. [The Component Gallery](https://component.gallery/)

A reference library comparing how established design systems solve the same UI element. It currently catalogs more than 2,600 examples across multiple systems.

### 8. [Godly](https://godly.website/)

A curated gallery of memorable websites. Good for finding unusual compositions and art direction beyond standard SaaS templates.

### 9. [Awwwards](https://www.awwwards.com/)

Recognized and ranked creative websites, with a focus on visual craft, interaction, and digital experience. Use it for inspiration, not as a checklist of effects to copy.

### 10. [Landing Love](https://www.landing.love/)

A showcase of expressive landing pages and animation-heavy websites. Useful for studying how transitions and scroll effects support a story.

### 11. [Land-book](https://land-book.com/)

A practical gallery of landing pages spanning product sites, agencies, portfolios, and campaigns.

### 12. [Mobbin](https://mobbin.com/)

Real-world mobile UI patterns and product flows. Start here when navigation, onboarding, or a multi-step interaction needs to feel familiar.

### 13. [Hover States](https://www.hoverstat.es/)

### 14. [Navbar Gallery](https://navbar.gallery/)

Navigation-pattern inspiration. Compare structures, responsive behavior, menu density, and information architecture.

### 15. [Footer Design](https://www.footer.design/)

Footer layout references for sites that need to conclude a page cleanly and still guide visitors toward the next action.

### 16. [CTA Gallery](https://www.cta.gallery/)

A visual collection of calls to action, forms, pop-ups, and buttons. Useful for conversion-oriented design inspiration; actual conversion performance still needs testing on your audience.

Hero-section inspiration for finding a sharper above-the-fold composition, headline treatment, and first-screen hierarchy.

### 18. [Pricing Pages](https://pricingpages.design/)

Examples of pricing-page layouts, plan comparisons, feature tables, and packaging patterns.

## Components, effects, and frontend building blocks

### 19. [21st.dev](https://21st.dev/)

A community marketplace of UI components, themes, and templates. Its CLI and MCP integration make it especially useful when an AI coding agent needs to search for, inspect, and bring component code into a project.

### 20. [shadcn/ui](https://ui.shadcn.com/)

An excellent foundation for accessible, customizable React UI patterns. You own the component code rather than treating a visual library as an opaque black box.

### 21. [Aceternity UI](https://ui.aceternity.com/)

Animated React and Tailwind components for expressive landing pages, backgrounds, cards, and interactions.

### 22. [Magic UI](https://magicui.design/)

Animated components and visual effects built for modern frontend stacks; useful for adding motion after the core experience works.

### 23. [Motion Primitives](https://motion-primitives.com/)

Reusable motion patterns for polished, intentional interactions without inventing every transition from zero.

### 24. [Uiverse](https://uiverse.io/)

Community-created UI elements and CSS interaction ideas, including buttons, toggles, loaders, and cards.

### 25. [Smooth UI](https://smoothui.dev/)

Animated UI components and effects with a focus on Motion- and GSAP-powered interactions.

### 26. [shadcnblocks](https://www.shadcnblocks.com/)

A large catalog of prebuilt sections and layout blocks designed around the shadcn/ui ecosystem.

### 27. [Kinetics by Colorion](https://kinetics.colorion.co/)

Motion-effect examples with React code and prompts, useful when you want to reproduce a particular interaction.

### 28. [Microkit](https://microkit.co/)

Small interaction ideas that can make feedback, transitions, and state changes feel more deliberate.

### 29. [Liquid Glass by Samasante](https://glass.samasante.com/)

Experiments with glass and refraction effects for the web. Treat effects like these as progressive enhancement, with contrast and performance in mind.

## My recommended stack for an AI-built website

For a **landing page**, I would start with Scrolltide for the visual prompt, use Refero Styles or DESIGN.md for consistent design decisions, lean on shadcn/ui or 21st.dev for real components, and implement with Claude Code or Cursor.

For a **dashboard**, begin with Mobbin and The Component Gallery to understand common patterns, then use shadcn/ui and targeted blocks. Prioritize readable data, responsive states, and accessibility over dramatic motion.

For a **creative portfolio**, study Awwwards, Godly, and Hover States. Reach for Motion Primitives, Anime.js, or Three.js only when the effect helps tell the story and your performance budget can accommodate it.

The rule I keep coming back to is simple: **inspiration gives your agent taste; design systems provide consistency; components supply implementation; tests and human review make the result trustworthy.**
