- **When:** September 17-18, 2026
- **Where:** RAI Amsterdam, Netherlands

## Why this one matters

The agentic stack is moving fast, and most of the hard problems are no longer "can a model do X" — they're about making agent systems that are **reliable, scalable, and secure** once they leave a notebook and hit real infrastructure. AGNTCon + MCPCon is where that conversation is happening: core agent architectures, orchestration, observability, the protocols (MCP first among them) that make tools and services interoperable, and the real-world case studies from teams running agents in production.

The audience matches that: open-source contributors building MCP and agentic projects, project maintainers and foundation leaders, enterprise engineers and architects adopting agent-based systems, platform and infrastructure teams supporting orchestration and security, and researchers exploring where agentic systems go next.

The confirmed keynotes already read like a who's-who of the protocol and agentic tooling world:

Beyond the keynotes, the program is organized into seven technical tracks that map to the full agent lifecycle:

- **Agentic Engineering** — harnesses, workflows, agent skills, context and memory design, cost and compute efficiency
- **Building Reliable Agent Systems** — architecture patterns, guardrails and sandboxing, observability, production failure modes
- **Evals & Testing** — regression suites, evaluation pipelines, release gates for systems that reason and act
- **Human-Agent Collaboration** — approval workflows, trust interfaces, keeping humans meaningfully in the loop
- **Interoperability & Standards** — agent identity and delegation, access control boundaries, open protocols
- **MCPCon** — the MCP 2026-07-28 specification (stateless core, extensions framework, authorization changes), migration strategies, and production lessons
- **Enterprise Adoption in Practice** — real case studies, cost management, regulated-industry constraints, organizational patterns
- **Agentic Commerce** — the protocols and infrastructure for agents that shop, sell, and pay on behalf of people and businesses

Workshops — no extra fee, included with registration — cover human-agent collaboration in shared workflows, building autonomous coding-agent harnesses, implementing persistent agent memory, securing and routing MCP and LLM traffic through an agent gateway, and governing agent actions across MCP servers, CLIs, Skills, and agent-generated code.

There's also a **Model Context Protocol Associate (MCPA) certification** available alongside the event if you want to put a credential next to the hands-on work.
