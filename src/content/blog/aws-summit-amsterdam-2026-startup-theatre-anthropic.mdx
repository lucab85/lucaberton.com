![AWS Startup Theatre — Veronica Östring presenting](/blog/events/aws-summit-amsterdam-2026-startup-theatre.jpg)

The session combined an overview of AWS startup programs with a fireside discussion about the Anthropic partnership and what it means for builders choosing Claude as their foundation model.

## AWS Activate: Credits to Extend Your Runway

![AWS Startup Credits](/blog/events/aws-summit-amsterdam-2026-startup-credits.jpg)

Veronica broke down the **AWS Activate** credit tiers:

- **Founders**: $1,000 in AWS credits — for self-funded, bootstrapped startups not affiliated with an Activate Provider
- **Portfolio**: Up to $100,000 in AWS credits — for startups funded up to Series A and affiliated with an Activate Provider

**Key detail**: AWS credits now cover third-party models on Amazon Bedrock — meaning your Activate credits pay for Claude, GPT, Mistral, Llama, and every other model in the catalog. That is a game-changer for AI startups managing inference costs.

## AWS Startup Program: Three Stages

![AWS Startup Program stages](/blog/events/aws-summit-amsterdam-2026-startup-program.jpg)

The program follows a clear progression:
1. **Get Started** — initial setup, Activate credits, technical guidance
2. **Build Fast** — architecture reviews, Well-Architected Framework, solutions architects
3. **Accelerate Growth** — co-selling through AWS Marketplace, enterprise customer introductions

## Startup Migrations Program

![Startup Migrations](/blog/events/aws-summit-amsterdam-2026-startup-migrations.jpg)

For startups migrating from on-premise, colocation, or other cloud providers, AWS offers a dedicated **Startup Migrations** program:

**What you get:**
- AWS Migration credits
- Guidance from AWS experts
- AWS Partner cash for hands-on migration support from vetted AWS Migration Partners

**Featured migration partners:** Cloud Nation, DoiT, CloudVisor, Cognitve, Automat-it, Netlight, cloudzone

The key insight: AWS will literally pay a partner to help you migrate off a competitor. That is how badly they want startup workloads.

## The AWS + Anthropic Partnership

The fireside chat revealed how deep the AWS-Anthropic relationship goes beyond just hosting Claude on Bedrock:

- **Joint GTM programs** — helping startups go from prototype to production with Claude
- **Credits and support** — AWS Activate provides infrastructure credits while Anthropic provides model access
- **Technical collaboration** — optimising Claude inference on AWS custom silicon (Trainium, Inferentia)
- **Enterprise bridge** — startups building on Claude via Bedrock can scale to enterprise customers through AWS Marketplace

This aligns with what we saw in the keynote: AWS announced **Bedrock Managed Agents powered by OpenAI** (including GPT 5.5), but Anthropic remains the strategic AI partner with the deepest integration across the AWS ecosystem.
