## Workshop Structure

### Part 1: Welcome, Setup and AI-First Mindset

What makes Claude Code different from autocomplete tools. The **plan → implement → test → review → commit** workflow. Safe delegation vs blind trust.

### Part 2: Prompting Claude Code Like a Tech Lead

Big prompts vs small prompts. Writing task briefs with acceptance criteria. How to intervene without micromanaging. The difference between delegating a task and writing code yourself.

### Part 3: Project Context with CLAUDE.md

Why Claude Code needs project context. Architecture notes, coding conventions, security rules, and "do not touch" zones. Keeping context concise under token limits. This is where most developers go wrong — and where the biggest productivity gains hide.

### Part 4: Advanced Workflows

Best-of-N prompting for exploring solution spaces. Git discipline with AI-generated code. Converting visual designs into working implementations. Testing strategies for AI-written code.

### Part 5: Production Readiness

Security reviews, CI/CD thinking, deployment checklists, and safe AI practices. Going beyond "it works" to "it is ready to ship."
