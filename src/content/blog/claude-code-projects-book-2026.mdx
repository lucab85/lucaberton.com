## Why a Book About Claude Code?

Claude Code changed how I build software. It is not a suggestion engine — it is a tool-use engine that can read files, run commands, control a browser, review a pull request, and hook into your CI/CD pipeline. The gap I kept seeing in teams is not that they lack access to a good model; it is that they never move beyond autocomplete. They prompt, copy, and paste, and stop.

*Claude Code Projects* closes that gap. It teaches the workflows I use daily to ship production systems, structured around ten real projects so every chapter ends in something you can run and reuse.

## The Core Loop

Every project in the book follows the same five-step loop, which is also the loop I run in production with AI-assisted work:

1. **Plan** — give Claude the task and the acceptance criteria before it writes code.
2. **Implement** — delegate the work, then read what it produced.
3. **Test** — verify the result against the criteria, not your gut.
4. **Review** — treat every diff like a pull request from a colleague.
5. **Commit** — ship only when the loop passes.

This loop is the spine of the book. It turns "AI that writes code" into "AI that participates in the full development lifecycle."

## Why It Works: Skills, Hooks, and MCP

Three mechanisms do the heavy lifting, and they map directly onto how production systems are built:

- **Skills** let you encode repeatable, high-quality procedures that Claude applies on demand — the same idea as a well-tested runbook or a battle-tested playbook.
- **Hooks** are automated guardrails that run before or after a tool call. A pre-tool-use hook can *block* an action (for example, reading a `.env` file); a post-tool-use hook can run a type check and feed errors back for automatic correction.
- **MCP (Model Context Protocol)** servers give Claude new capabilities — a browser, a database, a deployment pipeline — so it stops being just a code editor and becomes a full automation tool.

For teams already running AI workloads on Kubernetes and building agentic pipelines, this model maps naturally onto the [Agent Client Protocol](/blog/agent-client-protocol-acp-standardizing-ai-coding-agents-2026/) vision of composable, interoperable AI tooling.
