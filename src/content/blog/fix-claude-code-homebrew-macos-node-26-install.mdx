## The Problem

You try to run `claude` on macOS and hit one (or all) of these:

1. **Binary conflict** — `/opt/homebrew/bin/claude` already exists from an old npm global install
2. **Node.js v26 crash** — the CLI launches via Node.js v26.0.0 and immediately crashes
3. **Gatekeeper block** — "Apple could not verify claude is free of malware"

This guide walks through the complete fix I used to get Claude Code v2.1.149 running cleanly.

## Root Cause

The install is half-conflicting: Homebrew tries to install the new `claude-code` cask, but `/opt/homebrew/bin/claude` already exists from a previous `npm install -g @anthropic-ai/claude-code`. That old npm launcher, not the cask, is what ran through Node.js v26.0.0 and crashed.

The Homebrew cask and the native installer ship a self-contained binary and do not use your system Node.js at all. Only the npm package cares about Node: it requires Node.js 22 or later, and current versions download the same native binary, which does not invoke Node at runtime.

## Step 1: Identify the Conflict

```bash
# See what currently owns the claude binary
which claude
ls -l /opt/homebrew/bin/claude
```

If it points to a Node.js script or npm global, that's your problem.

## Step 2: Remove the Old npm Install

```bash
# Remove the global npm package
npm uninstall -g @anthropic-ai/claude-code

# Check what is left on your PATH
which -a claude
```

Only if `which -a claude` still lists `/opt/homebrew/bin/claude` and `ls -l /opt/homebrew/bin/claude` shows it is a dangling npm launcher (pointing into a deleted `node_modules`), remove that one file:

```bash
rm /opt/homebrew/bin/claude
```

## Step 3: Reinstall via Homebrew Cask

```bash
# Clean install of the official cask
brew install --cask claude-code

# Verify
claude --version
```

Expected output:

```
2.1.149 (Claude Code)
```

## Step 4: Still Launching via Node? Don't Change Your System Node

You do not need to downgrade or relink Node.js. Replacing the system `node` with `node@22` affects every other project on your Mac, and the Homebrew cask never uses it anyway.

If `claude` still launches via Node and crashes, an npm install is still first on your PATH. Remove it (Step 2) and keep only the Homebrew cask, or use the native installer instead:

```bash
curl -fsSL https://claude.ai/install.sh | bash

# Open a new terminal, then verify a single install
which -a claude
claude --version
```

If you deliberately want the npm package, use Node.js 22 or later and install with `npm install -g @anthropic-ai/claude-code@latest` (never with `sudo`).

## Step 5: Fix macOS Gatekeeper Block

When you see "Apple could not verify claude is free of malware":

**Option A — System Settings UI:**

The official macOS binary is signed by "Anthropic PBC" and notarized by Apple, so this warning is unexpected. Check the binary before you override anything:

```bash
CLAUDE_BIN="$(readlink -f "$(command -v claude)")"
echo "$CLAUDE_BIN"
xattr -l "$CLAUDE_BIN"
codesign --verify --verbose "$CLAUDE_BIN"
codesign -dv --verbose=2 "$CLAUDE_BIN" 2>&1 | grep -E 'Authority|TeamIdentifier'
spctl --assess --type execute -vv "$CLAUDE_BIN"
```

If the signature is not Anthropic's, or `codesign` reports it as invalid, do not bypass Gatekeeper: delete it and reinstall from the official source (`brew reinstall --cask claude-code` or the native installer). Reinstalling from the official source is the preferred fix in any case.

**Option A — System Settings UI:**

1. Run `claude` (it will fail)
2. Go to **System Settings → Privacy & Security → Security**
3. Click **"Open Anyway"** right after the blocked attempt
4. Run `claude` again

**Option B — Terminal (only for a binary you verified above):**

Remove the quarantine flag from that one binary, not from the whole Caskroom folder:

```bash
xattr -d com.apple.quarantine "$CLAUDE_BIN"
claude
```

On a managed Mac, ask IT first: MDM policy may forbid overriding Gatekeeper.

## Step 6: Nuclear Option (Clean Reinstall)

If nothing else works:

```bash
brew uninstall --cask claude-code
npm uninstall -g @anthropic-ai/claude-code   # if an npm install is still around
which -a claude                              # should print nothing now
brew install --cask claude-code
claude
```

## First-Time Setup

Once Claude Code launches, you'll see the welcome screen with a theme selector:

```
1. Auto (match terminal)
2. Dark mode ✔
3. Light mode
4. Dark mode (colorblind-friendly)
5. Light mode (colorblind-friendly)
6. Dark mode (ANSI colors only)
7. Light mode (ANSI colors only)
```

Use arrow keys to select, press Enter. You can change this later with `/theme`.

## Summary

| Problem | Fix |
|---------|-----|
| Binary conflict | `npm uninstall -g @anthropic-ai/claude-code` then `brew install --cask claude-code` |
| Node.js v26 crash | Remove the npm install; the cask and native installer don't use your Node.js |
| Gatekeeper block | Verify with `codesign`/`spctl`, reinstall from the official source, or Open Anyway / `xattr -d com.apple.quarantine` on that one binary |
