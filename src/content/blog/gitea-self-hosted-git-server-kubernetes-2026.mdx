## Why Gitea?

[Gitea](https://github.com/go-gitea/gitea) is a painless, self-hosted Git service. A single Go binary that provides GitHub-like functionality at a fraction of the resource cost. 47K+ stars.

| Feature | Gitea | GitLab CE | GitHub |
|---------|-------|-----------|--------|
| Memory (idle) | 50MB | 4GB+ | N/A (SaaS) |
| Setup time | 5 minutes | 30+ minutes | Instant |
| CI/CD | ✅ Gitea Actions (GitHub-compatible) | ✅ Built-in | ✅ Actions |
| Package registry | ✅ (Container, npm, Maven, PyPI) | ✅ | ✅ |
| Self-hosted | ✅ | ✅ | ❌ (Enterprise only) |
| License | MIT | MIT (CE) | Proprietary |

## Kubernetes Deployment

```bash
helm repo add gitea-charts https://dl.gitea.com/charts/
helm install gitea gitea-charts/gitea \
  --namespace gitea --create-namespace \
  --set gitea.admin.username=admin \
  --set gitea.admin.password=changeme \
  --set persistence.size=50Gi \
  --set postgresql-ha.enabled=true \
  --set redis-cluster.enabled=true \
  --set ingress.enabled=true \
  --set ingress.hosts[0].host=git.yourdomain.com
```

## Gitea Actions (GitHub-Compatible)

```yaml
# .gitea/workflows/ci.yml — same syntax as GitHub Actions!
name: CI
on: [push, pull_request]
jobs:
  test:
    runs-on: ubuntu-latest
    steps:
      - uses: actions/checkout@v4
      - uses: actions/setup-go@v5
        with:
          go-version: '1.23'
      - run: go test ./...
      - run: go build -o app .
```

Gitea Actions runners are compatible with GitHub Actions workflows — most workflows work without modification.

## Migration from GitHub/GitLab

```bash
# Gitea can mirror repos automatically
# Admin → Site Administration → Migrations
# Supports: GitHub, GitLab, Bitbucket, Gitea, Gogs

# Or via API:
curl -X POST "https://git.yourdomain.com/api/v1/repos/migrate" \
  -H "Authorization: token YOUR_TOKEN" \
  -d '{
    "clone_addr": "https://github.com/org/repo.git",
    "mirror": true,
    "repo_name": "repo",
    "service": "github"
  }'
```
