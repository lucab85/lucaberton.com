Here is how to install Helm on Ubuntu 24.04 LTS. Tested and verified.

## Prerequisites

- Ubuntu 24.04 LTS installed and updated
- Root or sudo access
- Internet connection

## Step 1: Update System

```bash
sudo apt update && sudo apt upgrade -y
```

## Step 2: Add Official Repository

Ubuntu's own archive has no `helm` package, so add the Helm apt repository first (a community package hosted by Buildkite, as listed in the Helm docs). The official script, `curl -fsSL https://raw.githubusercontent.com/helm/helm/main/scripts/get-helm-4 | bash`, is the alternative.

```bash
# Add the Helm apt repository
sudo apt-get install -y curl gpg
curl -fsSL https://packages.buildkite.com/helm-linux/helm-debian/gpgkey > "${TMPDIR:-/tmp}/helm.asc"
gpg --import --import-options=show-only --with-colons "${TMPDIR:-/tmp}/helm.asc" | awk -F: '$1 == "fpr" {print $10}' | head -n 1
# Must print DDF78C3E6EBB2D2CC223C95C62BA89D07698DBC6; stop if it does not
sudo install -m 0644 -Dt /etc/apt/keyrings/ "${TMPDIR:-/tmp}/helm.asc"
sudo tee /etc/apt/sources.list.d/helm-stable-debian.sources > /dev/null <<EOF
Types: deb
URIs: https://packages.buildkite.com/helm-linux/helm-debian/any/
Suites: any
Components: main
Signed-By: /etc/apt/keyrings/helm.asc
EOF
```

## Step 3: Install Helm

```bash
sudo apt-get update
sudo apt-get install -y helm
```

## Step 4: Verify Installation

```bash
helm version
```

Expected output should show the installed version.

## Step 5: Post-Install Configuration

Helm is a client binary: there is no `helm` service to enable. It uses the same kubeconfig as `kubectl`.

```bash
# Check that Helm can reach your cluster
kubectl get nodes
helm list -A
```

## Troubleshooting

### Package Not Found

Make sure the repository was added correctly:

```bash
# Show which repository provides helm
apt-cache policy helm
```

### Permission Denied

There is no `helm` group. Helm uses the credentials in your kubeconfig (`~/.kube/config` or `$KUBECONFIG`); check that the file is readable and that `kubectl` works with it:

```bash
ls -l ~/.kube/config
kubectl auth can-i list pods
```

## Uninstall

```bash
sudo apt-get remove -y helm
```
