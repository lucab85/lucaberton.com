Install Helm on Ubuntu in 2026 using three methods: the official script (fastest), APT repository (easiest updates), or Snap (simplest). Tested and verified.

## Prerequisites

- Ubuntu 22.04 or 24.04 LTS
- `kubectl` configured with cluster access
- sudo privileges

## Method 1: Official Script (Recommended)

```bash
curl https://raw.githubusercontent.com/helm/helm/main/scripts/get-helm-4 | bash
```

## Method 2: APT Repository

```bash
curl -fsSL https://packages.buildkite.com/helm-linux/helm-debian/gpgkey > "${TMPDIR:-/tmp}/helm.asc"
gpg --import --import-options=show-only --with-colons "${TMPDIR:-/tmp}/helm.asc" | awk -F: '$1 == "fpr" {print $10}' | head -n 1
# Must print DDF78C3E6EBB2D2CC223C95C62BA89D07698DBC6; stop if it does not
sudo install -m 0644 -Dt /etc/apt/keyrings/ "${TMPDIR:-/tmp}/helm.asc"
sudo tee /etc/apt/sources.list.d/helm-stable-debian.sources > /dev/null <<EOF
Types: deb
URIs: https://packages.buildkite.com/helm-linux/helm-debian/any/
Suites: any
Components: main
Signed-By: /etc/apt/keyrings/helm.asc
EOF
sudo apt-get update
sudo apt-get install helm
```

## Method 3: Snap

```bash
sudo snap install helm --classic
```

## Verify Installation

```bash
helm version
helm env
```

## Post-Installation Setup

```bash
# Add common repositories (the old "stable" repo has been an unmaintained archive since November 2020)
helm repo add bitnami https://charts.bitnami.com/bitnami
helm repo add prometheus-community https://prometheus-community.github.io/helm-charts
helm repo update

# Test with a chart
helm search repo nginx
```

## Quick Start

```bash
# Install a chart
helm install my-nginx bitnami/nginx

# List releases
helm list

# Uninstall
helm uninstall my-nginx
```
