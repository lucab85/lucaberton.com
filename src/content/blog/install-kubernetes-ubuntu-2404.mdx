Here is how to install Kubernetes on Ubuntu 24.04 LTS. Tested and verified.

## Prerequisites

- Ubuntu 24.04 LTS installed and updated
- Root or sudo access
- Internet connection

## Step 1: Update System

```bash
sudo apt update && sudo apt upgrade -y
```

## Step 2: Add Official Repository

Kubernetes should be installed from the official repository to get the latest stable version and security updates. The packages live at `pkgs.k8s.io`, with one repository per minor version (1.35 to 1.37 are supported).

```bash
# Add the official Kubernetes repository (v1.37)
sudo apt-get update
sudo apt-get install -y apt-transport-https ca-certificates curl gpg
sudo mkdir -p -m 755 /etc/apt/keyrings
curl -fsSL https://pkgs.k8s.io/core:/stable:/v1.37/deb/Release.key | sudo gpg --dearmor -o /etc/apt/keyrings/kubernetes-apt-keyring.gpg
echo 'deb [signed-by=/etc/apt/keyrings/kubernetes-apt-keyring.gpg] https://pkgs.k8s.io/core:/stable:/v1.37/deb/ /' | sudo tee /etc/apt/sources.list.d/kubernetes.list
```

## Step 3: Install Kubernetes

There is no `kubernetes` package. Install the three components instead: `kubelet`, `kubeadm` and `kubectl`.

```bash
sudo apt-get update
sudo apt-get install -y kubelet kubeadm kubectl
sudo apt-mark hold kubelet kubeadm kubectl
sudo systemctl enable --now kubelet
```

## Step 4: Verify Installation

```bash
kubeadm version
kubectl version --client
```

Expected output should show the installed version.

## Step 5: Post-Install Configuration

There is no `kubernetes` service. The kubelet restarts every few seconds until you bootstrap a cluster with `kubeadm init`, which also needs a container runtime such as containerd and swap turned off. See the [container runtimes](https://kubernetes.io/docs/setup/production-environment/container-runtimes/) page.

```bash
# Bootstrap the control plane
sudo kubeadm init --pod-network-cidr=10.244.0.0/16

# Let your user run kubectl
mkdir -p $HOME/.kube
sudo cp -i /etc/kubernetes/admin.conf $HOME/.kube/config
sudo chown $(id -u):$(id -g) $HOME/.kube/config

# Verify status (the node stays NotReady until you install a CNI plugin)
kubectl get nodes
```

## Troubleshooting

### Package Not Found

Make sure the repository was added correctly:

```bash
# List configured repositories
apt-cache policy
```

### Permission Denied

There is no `kubernetes` group. `kubectl` reads its credentials from `~/.kube/config`, so copy `admin.conf` as shown in Step 5:

```bash
ls -l $HOME/.kube/config
```

## Uninstall

```bash
sudo kubeadm reset
sudo apt-mark unhold kubelet kubeadm kubectl
sudo apt-get remove -y kubelet kubeadm kubectl
```
