Here is how to install Terraform on Fedora 41. Tested and verified.

## Prerequisites

- Fedora 41 installed and updated
- Root or sudo access
- Internet connection

## Step 1: Update System

```bash
sudo dnf update -y
```

## Step 2: Add Official Repository

Terraform is distributed through HashiCorp's official dnf repository. Download the repository definition and register it before installing:

```bash
# Download the official HashiCorp repository definition for Fedora
wget -O- https://rpm.releases.hashicorp.com/fedora/hashicorp.repo | sudo tee /etc/yum.repos.d/hashicorp.repo

# Refresh the package metadata cache
sudo dnf makecache
```

## Step 3: Install Terraform

```bash
sudo dnf install -y terraform
```

## Step 4: Verify Installation

```bash
terraform version
```

Expected output should show the installed version, for example `Terraform v1.x.x`.

## Step 5: Enable Shell Autocomplete

Terraform is a CLI binary with no background service, so there is nothing to enable or start with systemd. Instead, enable tab-completion for your shell:

```bash
terraform -install-autocomplete
```

This appends the completion hook to your shell profile (`~/.bashrc` for Bash). Restart your shell or run `source ~/.bashrc` for it to take effect.

## Troubleshooting

### GPG Key or Signature Errors

If `dnf` reports a GPG check failure when installing, import the HashiCorp signing key manually and retry:

```bash
sudo rpm --import https://rpm.releases.hashicorp.com/gpg
sudo dnf clean all && sudo dnf makecache
```

### Package Not Found

Confirm the repository file exists and the metadata cache is current:

```bash
cat /etc/yum.repos.d/hashicorp.repo
sudo dnf clean all && sudo dnf makecache
dnf list terraform
```

If `dnf list terraform` returns "Error: No matching Packages to list", the repository file is missing or stale — repeat Step 2. Note that HashiCorp's dnf repository publishes `x86_64` packages only; on `aarch64` Fedora installs, `dnf install terraform` will report no match because there is no official ARM RPM build.

## Uninstall

```bash
sudo dnf remove -y terraform
```
