Here is how I install Terraform on Windows 10 and 11 in 2026. Pick one method. winget is the quickest, because it ships with Windows 11 and recent Windows 10 builds.

## Method 1: winget (Recommended)

```powershell
winget install --exact --id Hashicorp.Terraform
```

Open a **new** PowerShell window afterwards. The old one still has the old `PATH`.

## Method 2: Chocolatey

Run PowerShell as Administrator:

```powershell
choco install terraform
```

## Method 3: Scoop

```powershell
scoop install terraform
```

## Method 4: Manual Download (ZIP)

1. Download the Windows `amd64` ZIP from https://releases.hashicorp.com/terraform/
2. Extract `terraform.exe` to a folder such as `C:\tools\terraform`
3. Add that folder to your user `PATH`:

```powershell
$dir = "C:\tools\terraform"
$userPath = [Environment]::GetEnvironmentVariable("Path", "User")
[Environment]::SetEnvironmentVariable("Path", "$userPath;$dir", "User")
```

Then open a new terminal.

## Verify

```powershell
terraform -version
where.exe terraform
```

`where.exe` also tells you which `terraform.exe` wins if you have more than one.

## Upgrade Terraform

```powershell
winget upgrade --id Hashicorp.Terraform   # winget
choco upgrade terraform                   # Chocolatey
scoop update terraform                    # Scoop
```

For a manual install, replace `terraform.exe` with the newer build.

## Fix: "terraform is not recognized"

PowerShell says `The term 'terraform' is not recognized as the name of a cmdlet...` and cmd says `'terraform' is not recognized as an internal or external command`. Both mean Windows cannot find `terraform.exe` on your `PATH`.

- Close and reopen the terminal, and VS Code, after installing. Open windows keep the old `PATH`.
- Run `where.exe terraform`. No result means the folder is not on `PATH`.
- For a manual install, make sure `PATH` points at the folder that contains `terraform.exe`, not its parent.

## Tab Completion

`terraform -install-autocomplete` supports Bash and Zsh only. Run it from Git Bash or WSL. It does nothing for native PowerShell.

```bash
terraform -install-autocomplete
```

## Working in WSL?

Windows and WSL keep separate binaries. If you run your tooling inside WSL, install the Linux build there: see [Install Terraform on Ubuntu 24.04](/blog/install-terraform-ubuntu-2404/).
