## What Is n8n?

[n8n](https://github.com/n8n-io/n8n) is a workflow automation platform with 400+ integrations, AI agent capabilities, and a visual node editor. 60K+ GitHub stars — the open-source Zapier/Make alternative.

### n8n vs Zapier vs Make

| Feature | n8n | Zapier | Make |
|---------|-----|--------|------|
| Self-hosted | ✅ | ❌ | ❌ |
| Open source | ✅ (fair-code) | ❌ | ❌ |
| Code nodes | ✅ JS/Python | ❌ | ⚠️ Limited |
| AI agents | ✅ Native | ⚠️ Beta | ⚠️ Limited |
| Branching/loops | ✅ | ⚠️ Paths | ✅ |
| Error handling | ✅ Per-node | ⚠️ Basic | ✅ |
| Price (self-hosted) | $0 | N/A | N/A |
| Executions (cloud) | 2,500 free | 100 free | 1,000 free |

## Kubernetes Deployment

```yaml
apiVersion: apps/v1
kind: Deployment
metadata:
  name: n8n
  namespace: automation
spec:
  replicas: 1
  template:
    spec:
      containers:
        - name: n8n
          image: n8nio/n8n:latest
          ports:
            - containerPort: 5678
          env:
            - name: DB_TYPE
              value: "postgresdb"
            - name: DB_POSTGRESDB_HOST
              value: "postgres.automation.svc"
            - name: DB_POSTGRESDB_DATABASE
              value: "n8n"
            - name: DB_POSTGRESDB_USER
              value: "n8n"
            - name: DB_POSTGRESDB_PASSWORD
              valueFrom:
                secretKeyRef:
                  name: n8n-secrets
                  key: db-password
            - name: N8N_ENCRYPTION_KEY
              valueFrom:
                secretKeyRef:
                  name: n8n-secrets
                  key: encryption-key
            - name: WEBHOOK_URL
              value: "https://n8n.yourdomain.com"
            - name: EXECUTIONS_MODE
              value: "queue"
            - name: QUEUE_BULL_REDIS_HOST
              value: "redis.automation.svc"
          volumeMounts:
            - name: data
              mountPath: /home/node/.n8n
          resources:
            requests:
              memory: "512Mi"
              cpu: "500m"
            limits:
              memory: "2Gi"
              cpu: "2"
```

### Queue Mode (Production Scaling)

```yaml
# Worker deployment for processing executions
apiVersion: apps/v1
kind: Deployment
metadata:
  name: n8n-worker
spec:
  replicas: 3  # Scale workers independently
  template:
    spec:
      containers:
        - name: n8n-worker
          image: n8nio/n8n:latest
          command: ["n8n", "worker"]
          env:
            - name: EXECUTIONS_MODE
              value: "queue"
            - name: QUEUE_BULL_REDIS_HOST
              value: "redis.automation.svc"
```

## AI Agent Workflows

n8n has native AI agent support with tool-calling:

```json
{
  "nodes": [
    {
      "type": "n8n-nodes-base.webhook",
      "name": "Webhook Trigger"
    },
    {
      "type": "@n8n/n8n-nodes-langchain.agent",
      "name": "AI Agent",
      "parameters": {
        "model": "gpt-4-turbo",
        "systemMessage": "You are a helpful assistant with access to tools.",
        "tools": ["Google Search", "Calculator", "Database Query"]
      }
    },
    {
      "type": "n8n-nodes-base.slack",
      "name": "Send to Slack"
    }
  ]
}
```

## Common Automation Patterns

### 1. Lead Enrichment Pipeline
```
Webhook (new lead) → ClearBit Enrich → Score Lead → 
  IF score > 70: Create Salesforce Opportunity + Slack Alert
  ELSE: Add to Nurture Sequence
```

### 2. Content Publishing
```
RSS Feed (new post) → Extract Content → AI Summarize →
  Twitter Post + LinkedIn Post + Newsletter Draft
```

### 3. Infrastructure Alerting
```
Prometheus Webhook → Parse Alert → 
  IF critical: PagerDuty + Slack #incidents
  IF warning: Slack #monitoring
  Auto-create Jira ticket
```

### 4. Meeting Follow-up
```
Cal.com Webhook (meeting ended) → AI Generate Summary →
  Email Attendees + Update CRM + Create Tasks
```

## Self-Hosted Advantages

- **No execution limits** — run millions of workflows
- **Data privacy** — credentials never leave your infra
- **Custom nodes** — build proprietary integrations
- **Network access** — reach internal APIs, databases, services
- **Cost** — $0 vs $50-600/mo for cloud equivalents
