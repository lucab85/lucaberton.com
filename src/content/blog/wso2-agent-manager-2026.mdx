# WSO2 Agent Manager Brings Sovereign AI Governance to Enterprise Agent Sprawl

**WSO2** announced the general availability of **WSO2 Agent Manager** at AGNTCon + MCPCon Europe — an open control plane that governs AI agents across any framework, model, or deployment, helping enterprises put agents in production with confidence and regain control of agent sprawl.

## The Agent Sprawl Problem

As enterprises scale their agentic AI initiatives, a new problem has emerged: **agent sprawl**. Teams are independently spinning up agents built on different frameworks (LangGraph, CrewAI, AgnTCY, custom), connecting to different models (Claude, GPT, Gemini, open source), and deploying across different environments (public cloud, on-prem, edge).

The result is a patchwork of agents that:
- Can't be centrally governed
- Have no unified audit trail
- Can't enforce consistent security policies
- Can't be observed holistically

Zaithoon Wijeyeratne, Vice President at WSO2, explained the motivation: *"We built WSO2 Agent Manager because enterprises were telling us they had 50+ agents running with no central control plane. Agent sprawl is the new shadow IT."*

## What WSO2 Agent Manager Does

WSO2 Agent Manager provides a **sovereign, open control plane** that operates across any deployment model:

- **Framework agnostic** — works with LangChain, LangGraph, AgnTCY, OpenAI SDK, and custom agent frameworks
- **Model agnostic** — connects to any LLM provider, including closed and open-weight models
- **Deployment agnostic** — manages agents running in public cloud, on-prem, at the edge, or on desktop
- **Open standards** — integrates natively with MCP, A2A, and OpenTelemetry for observability

## Key Features

1. **Policy Enforcement** — Define and enforce governance policies (cost limits, tool access, data exfiltration prevention) across all agents
2. **Unified Observability** — Correlation logging, metric collection, and trace data in a single dashboard
3. **Cost Control** — Real-time budget tracking, model routing optimization, and spend attribution by team/project
4. **Security Controls** — Prompt injection detection, PII filtering, and compliance reporting (SOC 2, GDPR, EU AI Act)

## Open Source Foundation

True to WSO2's open source roots, Agent Manager is built on an open core model with the control plane available as open source under the Apache 2.0 license. This aligns with the conference's strong open-source ethos — 78% of teams at AGNTCon reported building on open-source tooling.

## Availability

WSO2 Agent Manager is available today under the Apache 2.0 license. Commercial support and enterprise features are available through WSO2 Subscriptions.
